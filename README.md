### Escola API — projeto principal
**API REST de gestão acadêmica** — Java 21 + Spring Boot 3

Sistema com Aluno, Professor, Curso e Usuário, construído para estudar arquitetura em camadas e segurança na prática, do zero.

- Arquitetura em camadas: `Controller → Service → Mapper → DTO → Entity → Repository`
- Autenticação JWT implementada manualmente (geração, validação, filtro customizado) e autorização por regra de negócio — cada usuário só edita o próprio cadastro
- Cadastro transacional que cria conta de usuário e perfil (aluno/professor) numa única operação, com validação cruzada entre campos
- Tratamento global de exceções com formato de erro padronizado, inclusive para falhas de autenticação/autorização
- Busca com filtros dinâmicos via `Specification` + `Pageable`
- DTOs segmentados por papel de acesso (visão administrativa vs. visão restrita)

**→ [github.com/MiguelWainst/escola-api](https://github.com/MiguelWainst/escola-api)**
