### Escola API
**API REST de gestão acadêmica** — Java 21 + Spring Boot 3

Sistema com Aluno, Professor, Curso e Usuário, construído para estudar arquitetura em camadas na prática.

- Arquitetura em camadas: `Controller → Service → Mapper → DTO → Entity → Repository`
- Busca com filtros dinâmicos via `Specification` + `Pageable`
- DTOs segmentados por papel de acesso (visão administrativa vs. visão restrita)
- Tratamento global de exceções customizadas
- Autenticação e autorização via JWT com Spring Security
